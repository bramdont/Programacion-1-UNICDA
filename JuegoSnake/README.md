# Juego Snake en C#

Proyecto completo del juego clasico Snake para consola en C#, listo para VS Code.

## Requisitos
- .NET SDK (6.0 o superior)
- Visual Studio Code con extension C#

## Instrucciones
1. Abre la carpeta JuegoSnake en VS Code.
2. Abre la terminal integrada (Ctrl + ~).
3. Ejecuta: dotnet run
4. Controles: ENTER para jugar, Flechas para moverte, ESC para salir.
